Safari

  1. 用 Safari 開啟呢個網站。
  2. 點 Safari 底部嘅 分享 按鈕（方框向上箭嘴）。
  3. 向下捲，揀 「加至主畫面」。
  4. 確認名稱後，點右上角 「加入」。

Chrome

  1. 用 Chrome 開啟呢個網站。
  2. 點網址列右邊嘅 分享 按鈕。
  3. 揀 「加至主畫面」。
  4. 確認名稱後，點右上角 「加入」。
